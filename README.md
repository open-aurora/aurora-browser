# Аврора Браузер (Aurora Browser)

Минималистичный, но полнофункциональный браузер для Linux. Сделан на Electron
с собственным интерфейсом: светлая тема, мягкие скругления, аккуратная типографика
и настройка внешнего вида под себя.

![Аврора Браузер](assets/icon.png)

## Запуск

```bash
./run.sh
```

или

```bash
npm start
```

Первый запуск создаёт данные профиля в `~/.config/Aurora`.
Ярлык **Аврора Браузер** добавлен в меню приложений (файл
`~/.local/share/applications/aurora.desktop`).

## Возможности

- **Поисковые системы** — Google, Яндекс, DuckDuckGo, Bing и Brave доступны
  для поиска из адресной строки и стартовой страницы; переключатель есть
  прямо рядом со строкой поиска.
- **Первый запуск** — анимированное приветствие помогает создать профиль:
  выбрать имя, поисковик и акцентный цвет. Выбор можно позже изменить в настройках.
- **Подсказки при поиске** — и в адресной строке, и на стартовой странице:
  история, закладки, быстрые ссылки, переход по адресу и поиск в выбранной
  системе. Выбор мышью или клавишами `↑`/`↓`, открытие — `Enter`, закрытие — `Esc`.
- **Умные подсказки** — при вводе в строку поиска Аврора Браузера предлагает продолжения
  запроса (история поиска, закладки, заголовки страниц, подсказки поисковой
  системы): например, «Иша» → «Ишак», «Ишак это», «Иша намаз» и т.д.
- **Вкладки** — создание, закрытие, перетаскивание, дублирование,
  восстановление случайно закрытой (`Ctrl+Shift+T`), контекстное меню.
- **Закладки** — звезда в адресной строке, панель закладок и отдельная панель
  со всеми сохранёнными страницами.
- **История** — с поиском, группировкой по дням и удалением записей.
- **Загрузки** — прогресс, открытие файла и показ в папке.
- **Поиск по странице** — `Ctrl+F` с количеством совпадений и переходами.
- **Блокировка рекламы и трекеров** — включается в настройках.
- **Восстановление сессии** — вкладки переживают перезапуск.
- **Экономия памяти** — неактивные вкладки засыпают и освобождают свои
  процессы, а сессия восстанавливается лениво (см. раздел «Память»).
- **Оформление** — 8 акцентных цветов + свой цвет, скругление, плотность,
  фон стартовой страницы, имя в приветствии, отключение анимаций.
- **Отдельная страница настроек** — как в обычных браузерах: разделы
  «Оформление», «Поиск и стартовая», «Вкладки и память», «Приватность»,
  «О браузере», живой предпросмотр, поиск по настройкам и редактор быстрых
  ссылок. Открывается из меню `⋮`, со стартовой страницы или по `Ctrl+,`.
- **Стартовая страница** — часы, приветствие, крупный поиск и редактируемые
  быстрые ссылки.
- **Страница ошибки** — аккуратная, с объяснением и кнопкой «Повторить».
- Контекстное меню страницы, масштаб, печать, исходный код, DevTools,
  полноэкранное видео без панелей.

## Память

Аврора Браузер специально сделан лёгким и не держит в памяти лишнего:

- **Ленивое восстановление сессии.** При запуске загружается только активная
  вкладка, остальные появляются в панели вкладок сразу, но читаются с диска
  только при клике. Это главный источник экономии: 6 восстановленных вкладок
  занимают память одной.
- **Сон неактивных вкладок.** Вкладка, которую не открывали 5 минут,
  освобождает свой процесс (иконка луны в панели вкладок). При клике она
  загружается заново; позиция прокрутки не сохраняется.
  Отключается в настройках → «Вкладки и память» → «Сон неактивных вкладок»
  или правым кликом по вкладке → «Отправить в сон».
- **«Освободить память»** в меню `⋮` или на странице настроек — сразу усыпляет
  все неактивные вкладки и очищает HTTP-кэш.
- **Настройки Chromium.** Один процесс рендеринга на сайт вместо одного на
  вкладку, лимит процессов, уменьшенный дисковый кэш, ограничение кучи V8
  (512 МБ), отключены перевод, Cast, back/forward-кэш, фоновые обновления и
  прочие неиспользуемые сервисы.
- **Лёгкий интерфейс.** Никаких расширений, телеметрии и фоновых сервисов;
  реклама и трекеры блокируются на уровне запросов.

Как честно мерить: Chromium многопроцессный, поэтому сумма «в диспетчере
задач» по одному процессу бессмысленна. Смотрите **PSS** по всем процессам
Electron (`/proc/<pid>/smaps_rollup`). Для сравнения на этой машине при шести
вкладках в панели:

| Сценарий | Процессов | Сумма PSS |
| --- | --- | --- |
| Обычное восстановление всех вкладок | 12 | ≈ 634 МБ |
| Аврора Браузер с ленивым восстановлением | 7 | ≈ 344 МБ |

То есть при том же наборе вкладок память меньше примерно вдвое. Одна активная
вкладка (например, Wikipedia) занимает ≈ 310–340 МБ PSS по всем процессам —
это нормальный уровень Chromium; дальше память растёт в основном от самих сайтов.

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Новая вкладка | `Ctrl+T` |
| Закрыть вкладку | `Ctrl+W` |
| Вернуть закрытую | `Ctrl+Shift+T` |
| Адресная строка | `Ctrl+L` |
| Настройки | `Ctrl+,` |
| Найти на странице | `Ctrl+F` |
| История | `Ctrl+H` |
| Загрузки | `Ctrl+J` |
| Обновить / без кэша | `Ctrl+R` / `Ctrl+Shift+R` |
| Закладка | `Ctrl+D` |
| Панель закладок | `Ctrl+Shift+B` |
| Масштаб | `Ctrl+-` / `Ctrl+=` / `Ctrl+0` |
| Назад / вперёд | `Alt+←` / `Alt+→` |
| Переключение вкладок | `Ctrl+Tab`, `Ctrl+1…9` |

## Технические детали

- Electron 45 (Chromium 142), собственный chrome UI на HTML/CSS/JS.
- Каждая вкладка — изолированный `WebContentsView`; интерфейс — отдельный
  процесс рендеринга. Настройки, стартовая и страница ошибки — внутренние
  страницы `aurora://`, обслуживаемые собственным протоколом.
- IPC ограничен preload-скриптами; доступ к привилегированному API получают
  только внутренние страницы `aurora://`.
- Настройки, история, закладки и сессия хранятся в JSON в каталоге профиля.
- Запуск на Wayland и X11. В `run.sh` используется `--no-sandbox`, потому что
  на ряде дистрибутивов (включая openSUSE) не работает штатная песочница
  Chromium; для максимальной изоляции можно убрать этот флаг.
